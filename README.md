# Flow & Code Lab

An interactive Year 10 app for learning pseudocode and flowcharts.

- `index.html` page structure
- `styles.css` all styling
- `app.js` lessons, flowchart visualizer and quiz

No build step. Open `index.html` locally, or import the repo into Vercel and deploy with the default settings (Framework Preset: Other, leave build command and output directory empty).
