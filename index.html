One idea, three ways to write it

An algorithm is a list of steps that solves a problem, like a recipe. Computer scientists write it in two ways before they write real code.

AlgorithmThe steps themselves, in order.
PseudocodeThe steps as short lines of plain, code-like English. Not a real language, so no strict rules.
FlowchartThe same steps as a map of shapes and arrows. You can see the choices.

Pseudocode words you need

Write one instruction per line. Indent the lines inside an IF or a WHILE. Always close them with ENDIF or ENDWHILE.

INPUT nAsk for a value and store it in n.
OUTPUT nShow something on the screen.
SET total TO 0Put a value in a variable. In a flowchart: total ← 0
IF … THEN … ELSE … ENDIFPick one of two paths. This is a decision diamond.
WHILE … DO … ENDWHILEKeep repeating while the answer is YES. A diamond with an arrow looping back.
n MOD 2The remainder after dividing. 7 MOD 2 = 1, so 7 is odd.
